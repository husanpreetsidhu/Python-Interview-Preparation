# 🐍 Python Interview Preparation

A collection of hands-on Python coding exercises, interview assignments, and problem-solving practice completed during my technical interview preparation.

This repository documents my learning journey through Python fundamentals, logic building, intermediate coding challenges, NumPy, and Pandas. It includes practice questions, code implementations, outputs, and debugging attempts.

## 🎯 Objectives

- Strengthen Python programming fundamentals.
- Improve logical thinking and problem-solving skills.
- Practice coding questions commonly used in technical interviews.
- Develop confidence in writing and debugging Python programs.
- Build practical experience with NumPy and Pandas.

### 1. Python Fundamentals
- Variables and data types
- Conditional statements
- Loops
- Strings and string manipulation
- Lists, tuples, sets, and dictionaries
- Functions

### 2. Logic Building & Problem Solving
- Reverse strings and words
- Find duplicate elements
- Find the second-largest number
- Count character and word frequency
- Calculate averages and totals
- Work with lists and dictionaries
- Solve number-based coding problems

### 3. Intermediate Python
- Nested dictionaries
- Data manipulation using loops
- Salary and employee-based problems
- Frequency analysis
- Multi-step coding challenges
- Exception handling and debugging

### 4. NumPy
- Array creation and manipulation
- Array indexing and slicing
- Mathematical operations
- Working with numerical data

### 5. Pandas
- DataFrame operations
- String manipulation using `.str`
- Working with columns
- Basic data manipulation
